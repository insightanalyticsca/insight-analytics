Universal Time Series Prediction: From Earthquakes to Bitcoin

By Insight Analytics · October 1, 2026 · 6 min read

The Problem with Forecasting Tools

Every forecasting tool on the market answers the same question differently: "What happens next with this data?" But most of them require you to know what model to use, how to prepare your data, and which parameters to tune before you even see a single prediction.

What if you could just paste a URL — any URL that points to time series data — and get a full analysis with forecasts, model benchmarks, and AI-powered insights? No setup, no configuration, no model selection. Just paste and read.

That's exactly what the universal predictor does.

How It Works

The predictor has two panels: a chat interface on the left and a dashboard on the right. You interact with both simultaneously.

On the chat side, you can:

  • Paste a URL to any CSV, JSON, or TSV file containing time series data
  • Drop a file directly into the browser (no upload to a server — everything is processed client-side)
  • Pick from a curated list of real-world data sources — earthquakes, river flows, crypto prices, climate data, space weather, economic indicators
  • Ask questions about the data in natural language (powered by Groq AI)

The bot reads your data, identifies the time column and value column automatically, runs the analysis, and the dashboard on the right lights up with results.

The Six Dashboard Views

Once the data is loaded, the dashboard gives you six different lenses on the same signal:

1. Series — the raw signal

The full time series plotted with interactive tooltips, zoom, and scroll. You see the shape of your data immediately — trends, seasonality, anomalies, gaps.

2. Predictions — the forecast

The model projects the next N periods forward, with confidence bands. You see not just "what will happen" but "how confident the model is" at each step.

3. Match-up — model vs. actual

A side-by-side comparison of the model's predictions against actual historical values. This is the honesty test — does the model actually fit the data, or is it hallucinating trends?

4. Rolling — rolling statistics

Rolling mean, rolling standard deviation, and rolling correlation. These reveal whether the signal's statistical properties are stable over time or shifting — critical for detecting regime changes.

5. Phase — phase space

A phase space plot (value vs. lagged value) reveals periodicities, attractors, and chaos in the signal. This is the view that turns a time series into a geometric object — and it's where patterns that are invisible in the time domain suddenly become obvious.

6. Dust Fields — advanced analytics

Additional analytical views that surface patterns the standard charts miss: autocorrelation, partial autocorrelation, spectral density, and residual diagnostics.

Real-World Data Sources

The predictor ships with a curated list of real-world data feeds you can analyze in one click:

  • Geophysical: USGS global earthquakes (30-day hourly counts), river flows (Potomac, Mississippi, Colorado, Sacramento), NOAA water levels
  • Climate: Open-Meteo temperature, wind speed, humidity, precipitation, soil temperature, air quality across multiple cities
  • Crypto: Bitcoin, Ethereum, Solana, Cardano, Polkadot daily prices (Binance + CoinGecko)
  • Space weather: NOAA GOES X-ray flux, magnetometer, electron/proton counts, solar wind speed, planetary K-index
  • Economic: World Bank GDP, CPI, unemployment (65 years of annual data)
  • Society: Wikimedia pageviews for any article over 2.5 years

Or paste any URL that returns CSV, JSON, or TSV with a date column and a numeric column. The predictor handles the parsing automatically.

The Architecture: Three Layers

Behind the scenes, the predictor is built as three clean layers:

Layer 1 — Data ingestion (client-side)

Everything runs in the browser. No server-side processing, no data upload. The predictor fetches the URL you paste (subject to CORS), parses CSV/JSON/TSV, identifies the time column and value column, and normalizes the series. This means your data never leaves your browser — a critical privacy guarantee for sensitive datasets.

Layer 2 — Forecasting engine

The engine benchmarks multiple forecasting approaches against your data: naive (persistence), moving average, seasonal naive, linear trend, and more. The best-performing model is selected automatically and used for the predictions view. The match-up view shows how each model performed against actual values so you can see the honest comparison.

Layer 3 — AI reasoning (Groq)

The chat interface connects to Groq (running a fast LLM) so you can ask questions about the data in natural language: "Is there a trend?", "What's the seasonal pattern?", "Is the forecast reliable?" The AI has access to the statistical summary, the chart data, and the model metrics — so its answers are grounded in the actual analysis, not generic text generation.

Why This Matters

Time series forecasting has traditionally been the domain of specialists — data scientists who know which model to use, how to tune hyperparameters, and how to interpret residual plots. The universal predictor democratizes this:

  • No setup: paste a URL and get results in seconds
  • No model selection: the engine benchmarks multiple models and picks the best one
  • No configuration: the dashboard auto-adapts to the data's characteristics (seasonality, trend, frequency)
  • AI explains: the chat bot translates statistical jargon into plain English
  • Privacy by design: everything runs client-side — your data never touches a server

For an executive who wants to understand whether a trend is real or noise, this tool answers the question in the time it takes to paste a URL. For a data scientist, it's a fast first-look tool that surfaces patterns before they commit to a full modeling pipeline.

The Visualization Layer

All six dashboard views are built with Apache ECharts — the same charting library we use across all our dashboards. ECharts was chosen for three reasons:

  • Performance: handles large datasets (10,000+ points) without lag
  • Interactivity: built-in zoom, pan, tooltips, and brush selection — no extra code needed
  • Consistency: the same visual language across every dashboard we build, so users don't have to relearn the UI

The dark/light theme toggle uses CSS variables, so the dashboard adapts to the user's preference instantly. The phase space view and dust fields view use ECharts custom series for bespoke visualizations that wouldn't be possible with standard chart types.

Persistence: Save and Compare

Every analysis can be saved to a GitHub repository (configured in the settings modal). This means:

  • Analyses are version-controlled — you can see how a forecast changed over time as new data arrived
  • Results are shareable — send a colleague a link to a saved analysis
  • The history modal lets you reload any past analysis and compare it side-by-side with a new one

The GitHub token stays in the browser's localStorage and is never sent anywhere except api.github.com — the predictor's own servers never see it.

What a First Look Reveals

If you paste the USGS earthquake feed, the predictor shows you the hourly count of global earthquakes over the last 30 days. The series view reveals a baseline rate with periodic spikes. The rolling view shows whether the rate is stable or trending up. The predictions view forecasts the next few days. The phase view reveals whether the timing of aftershocks follows a pattern.

If you paste Bitcoin daily closes, the series view shows the trend, the rolling view shows volatility clustering, the predictions view shows a forecast with widening confidence bands, and the match-up view shows where the model was right and where it was wrong.

Two completely different domains — geophysics and finance — analyzed by the same tool, with the same six views, in the same browser tab. That's the power of a universal predictor.
