What this showcase is

The Solutions Showcase is an illustrated catalog of representative application work Insight Analytics has shipped across operational analytics, contact-center data pipelines, billing workflows, security awareness reporting, and AI-assisted query tooling. Each project is presented as a dossier — a long-form, scrollable page section that describes the project's purpose, the toolkit, the working architecture, and an illustrative in-browser mockup of the running application.

The showcase has two jobs. First, it lets a technical evaluator (a CTO, a director of analytics, a senior engineer) scan a body of work quickly and decide which projects are relevant to their own situation. Second, it gives a non-technical evaluator (a CEO, a board member, a procurement lead) enough visual and written context to ask informed questions without needing a separate sales call.

Important — illustrative, not live. Every mockup in the showcase uses fictional sample data ("Sample A", "Group B", representative record shapes). The mockups reconstruct the real workflow patterns but they do not connect to production databases, mailboxes, or APIs. This is by design — production data and credentials are never shipped in a public-facing artifact.

How to use the workflow replay

The "Replay the workflow" panel inside each project mockup lets you watch representative records flow through the project's pipeline, one stage at a time.

  1. Open the project's dossier (click any project card on the projects index).
  2. Scroll to the mockup window labeled "Working local demo — Replay the workflow".
  3. Press Run replay to process all sample rows end-to-end, or press Advance one hop to step through one stage at a time and inspect the handoff at each stage.
  4. The Input panel shows the representative rows entering the pipeline. The Output panel shows what each row looks like after the workflow completes.
  5. Press Reset to clear the output and start over.

Workflow replay runs entirely in your browser using preset sample data. It does not connect to any production system.
