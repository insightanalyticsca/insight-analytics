Technology & Architecture
What technology stack do you use?
ECharts 5.5 for visualization (same engine across all deployments), Groq for AI narration (via Netlify edge proxy — key never reaches the browser), static hosting on GitHub Pages (zero ops), SQL Server / Snowflake / BigQuery / Postgres / Oracle as data sources. Technology-agnostic — we don't require you to rip and replace your stack. We require you to standardize the definitions, keys, and KPI rules.
What is ECharts and why do you use it?
ECharts is an open-source JavaScript visualization library (Apache-licensed) that renders interactive charts — bar, line, area, pie, heatmap, scatter, radar, gauge, treemap, sankey, funnel, boxplot, and more. We use it because it's free, performant (canvas + SVG rendering), mobile-friendly, and supports streaming animations. The same charts you see in our live demos run in 50+ production deployments.
What is Groq and how does the AI work?
Groq is a fast AI inference engine that runs open-source models like Qwen 3.8-27B. Our AI integration uses Groq via a Netlify edge proxy — the API key stays server-side, never reaches the browser, and never lives in the code repository. The AI narrates what the deterministic metadata discovery layer already proved: it writes briefs, answers questions, and explains trends — but never invents data or KPIs. No hallucination surface.
Do you work with SQL Server, Oracle, and Snowflake?
Yes. Our data pipelines connect to SQL Server, Oracle, Snowflake, BigQuery, Postgres, MySQL, and any system with an API. We don't require you to rip and replace your stack — we connect to what you already have. The dashboard engine is technology-agnostic; only the data source behind it changes.

AI & Intelligence
What is deterministic AI metadata discovery?
Metadata discovery applications walk even less-documented backends — legacy SQL Server, Oracle, multidimensional cubes, controlled files, SaaS APIs — and extract the actual business rules from stored procedures, functions, and view definitions. The discovered rules are deterministic (source code, parsed and structured), not model output. The AI narrates what the deterministic layer already proved — no hallucination surface. Explore the showcase →
What is a no-hallucination AI dashboard?
A no-hallucination AI dashboard uses deterministic metadata discovery to extract business rules from source code — not from AI generation. The AI then narrates what the deterministic layer already proved. The model is never asked to invent KPI definitions, guess column meanings, or fabricate data. Every claim links back to a discovered rule the analyst can audit.
What is an AI executive brief?
An AI executive brief is a 4-part narrative generated on page load: What happened (the headline change), Why (likely drivers), What to expect (direction only, no point forecast), What to do (recommended action). It's grounded in the dashboard's actual data — the AI reads the same KPIs the charts show, then writes a concise brief executives can act on. No invented numbers, no hallucinated confidence percentages.
What is metadata discovery and data lineage?
Metadata discovery walks your database schema, stored procedures, functions, and view definitions to extract the actual business rules — KPI calculations, joins, filters, transformations — that already exist in your code. Data lineage traces how data flows from source tables through transformations to final reports. Together, they eliminate the "six-week discovery phase" where analysts manually read code to understand what the data means.
