A Windows desktop application that connects to your SQL database, generates executive dashboards with AI narration, and deploys them to IIS — all through a guided wizard interface.

Download Demo See How It Works

What It Does

The Live Dashboard Builder is a Windows desktop application that turns raw SQL data into production-ready executive dashboards in minutes. It walks you through a series of guided dialogs — connect to Codex for AI narration, connect to your SQL source for live data — then automatically generates a complete dashboard website with interactive ECharts visualizations, KPI tiles, and AI-written narrative summaries.

Every dashboard the builder generates is a standalone HTML page. You can save individual charts as PNG images, export the full dashboard as a visual package, or deploy the entire thing to an IIS web server using the built-in IIS deployment guide.

Demo Version: This is a feature-limited demo. The full version supports additional data sources, scheduled refresh, role-based access, and multi-tenant deployment. Contact us for the full version.

Features

SQL Source Connection

Guided dialog connects to SQL Server, Azure SQL, or any ODBC-compatible source. Auto-discovers tables, views, and stored procedures. Live data refresh — no static snapshots.

AI Narration via Codex

Connects to Codex (Groq-powered) to generate plain-English narrative summaries of your data. Real interpretation, not just numbers.

Live ECharts Visuals

Generates interactive ECharts dashboards — bar, line, pie, heatmap, gauge, scatter. Tooltips, zoom, pan, legend toggle. Canvas renderer for performance.

PNG + Visual Export

Save any chart as a high-resolution PNG. Export the full dashboard as a self-contained visual package (HTML + CSS + JS) that runs anywhere.

IIS Deployment Guide

Built-in wizard walks you through deploying the generated dashboard to IIS — folder structure, web.config, MIME types, HTTPS bindings. No IIS expertise required.

Desktop Application

Runs as a native Windows EXE. No browser setup, no Node.js, no Docker. Double-click and go. Dialogs guide you through every step — no code required.

How It Works

The builder runs as a guided wizard. Each step is a dialog that collects one piece of configuration, then moves to the next. No code, no scripts, no command line.

  1. Launch the EXEDouble-click DashboardBuilder.exe. The splash screen loads, then the first dialog appears: "Connect to Codex for AI narration."
  2. Connect to Codex (AI Narration)Enter your Groq API key (or skip for dashboards without AI narration). The builder validates the key and shows a green checkmark when connected. This enables the AI-written executive summary at the top of every generated dashboard.
  3. Connect to SQL SourceThe next dialog asks for your SQL connection string. Choose from:

    OptionExample
    SQL Server (Windows Auth)Server=myserver;Database=mydb;Integrated Security=True
    SQL Server (SQL Auth)Server=myserver;Database=mydb;User Id=sa;Password=*****
    Azure SQLServer=tcp:myserver.database.windows.net,1433;Database=mydb;User Id=user@myserver;Password=*****
    ODBC (any source)DSN=MyDataSource;Uid=user;Pwd=*****
    The builder tests the connection, lists available tables and views, and lets you select which ones to include in the dashboard.
  4. Select Charts + KPIsFor each table/view you selected, the builder auto-detects columns and suggests chart types:
    • Date + numeric → Line chart (trend over time)
    • Category + numeric → Bar chart (comparison)
    • Two categories → Heatmap (cross-tab density)
    • Single metric → KPI tile (big number + delta)
    • Part-of-whole → Pie / donut chart
    You can override any suggestion — pick a different chart type, change colors, add filters, set thresholds.
  5. Generate the DashboardClick Generate. The builder fetches live data from your SQL source, renders ECharts visualizations, sends the data summary to Codex for AI narration, assembles a complete HTML dashboard page, and opens it in your default browser — live, interactive, ready to use.
  6. Export as PNG or Visual Package
    • Single chart PNG: Click the camera icon on any chart → saves a high-res PNG
    • Full dashboard export: File → Export → saves the complete HTML + CSS + JS as a self-contained folder
  7. Deploy to IISThe final dialog is the IIS Deployment Guide. It walks you through: creating the IIS site (folder path, site name, port), configuring web.config (MIME types, compression), setting up HTTPS (binding, certificate), and testing the deployed URL. Includes copy-paste commands for appcmd and PowerShell.
