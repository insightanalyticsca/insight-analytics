Business Rule Observatory
Dashboard Builder Demo

A Windows desktop application that generates executive dashboards from SQL data with AI narration. Works immediately with pre-built demo data — no setup required.

See How It Works

What It Does

Works immediately — no setup required. The demo includes pre-built database JSON files so you can generate dashboards right away without connecting to SQL or installing Codex. Just launch and click View sample report.

Business Rule Observatory is a Windows desktop application that turns raw SQL data into production-ready executive dashboards in minutes. It walks you through guided GUI dialogs — connect to Codex for AI narration (optional), connect to your SQL source for live data (optional) — then automatically generates a complete dashboard with interactive ECharts visualizations, KPI tiles, and AI-written narrative summaries.

Every dashboard is a standalone HTML page. Save individual charts as branded PNG images, export the full dashboard as a visual package, or deploy to IIS using the built-in deployment guide.

Demo Version: Limited to 4 visuals per dashboard. The full version supports unlimited visuals, scheduled refresh, multi-user access, and automated IIS deployment. Contact us for the full version.

Features

Works Immediately

Pre-built demo data included. Launch the EXE, click View sample report, explore dashboards instantly. No SQL server, no Codex, no setup.

SQL Source Connection

Guided dialog connects to SQL Server, Azure SQL, or ODBC. Auto-discovers tables and views. Live data refresh — no static snapshots.

AI Narration via Codex

Optional: connect Codex (ChatGPT CLI) for AI-written executive summaries. The wizard auto-detects existing installations or guides you through setup — all in the GUI, no terminal.

Live ECharts Visuals

Interactive charts — bar, line, pie, heatmap, gauge, scatter. Tooltips, zoom, pan, legend toggle. Click any chart to maximize to full screen.

Branded PNG Export

Save any chart as a high-resolution PNG with Insight Analytics branding. Export the full dashboard as a self-contained HTML package.

IIS Deployment Guide

Built-in wizard walks you through deploying dashboards to IIS — folder structure, web.config, MIME types, HTTPS bindings. No IIS expertise required.

How It Works

  1. Launch the EXEDouble-click BusinessRuleObservatory.exe. Choose View sample report (instant, no setup) or Connect ChatGPT (guided AI setup).
  2. Connect Codex — optionalThe wizard scans your machine for existing Codex installations (desktop app, PATH, npm, editor extensions, package managers). If found, shows a green checkmark. If not found, click Set up AI — the app downloads, verifies, and installs Codex automatically. Browser sign-in with a one-time code. No terminal needed.
  3. Connect to SQL — optionalDialog prompts for your connection string. Supports SQL Server (Windows/SQL auth), Azure SQL, ODBC. Tests connection, lists tables and views, auto-detects column types and suggests chart types.
  4. Generate DashboardClick Generate. The app fetches live data (or uses demo data), renders ECharts visuals, sends summary to Codex for AI narration (if connected), assembles HTML dashboard, opens in your browser.
  5. Explore + ExportMaximize any chart to full screen. Download any chart as a branded PNG. Export the full dashboard as a self-contained HTML folder.
No Codex installed? No problem. Click View sample report to explore the pre-built demo dashboard immediately. Codex setup is guided and automatic — the app downloads and installs it for you via Windows GUI dialogs, no terminal required.
